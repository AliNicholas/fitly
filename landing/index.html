Schema Layer

SQLite Relational Model

Fitly relies on clean relational structures, optimizing queries for rapid execution. All relationships are mapped locally:

// db/schema.ts
CREATE TABLE sessions (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  date TEXT NOT NULL,
  duration INTEGER
);

CREATE TABLE sets (
  id TEXT PRIMARY KEY,
  session_id TEXT REFERENCES sessions(id),
  weight REAL NOT NULL,
  reps INTEGER NOT NULL
);
local_sqlite_query.sql
SELECT SUM(weight * reps) AS volume FROM sets;
